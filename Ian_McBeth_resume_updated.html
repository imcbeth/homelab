Featured Project

🏠 Production Kubernetes Homelab Infrastructure

Technologies: Kubernetes 1.35, ArgoCD, Prometheus, Grafana, Terraform, Synology NAS, UniFi Networking

Overview: Designed and deployed a production-ready 5-node Raspberry Pi 5 Kubernetes cluster demonstrating enterprise-level capabilities on edge hardware. This project showcases practical expertise in modern DevOps practices and cloud-native technologies.

Key Achievements:

  • GitOps Implementation: Complete GitOps workflow managing 25+ applications with ArgoCD for automated, self-healing deployments
  • Comprehensive Monitoring: Prometheus + Grafana stack with 20+ custom dashboards, comprehensive alerting, and centralized logging via Loki/Promtail
  • Infrastructure as Code: Developed Terraform automation for UniFi network infrastructure, enabling version-controlled network management
  • Enterprise Storage Integration: Integrated Synology NAS with iSCSI CSI driver for persistent storage with 50Gi+ data retention
  • Network Architecture: Multi-VLAN design with Calico CNI, network policies, and comprehensive monitoring via UniFi Poller
  • Backup & DR: Implemented Velero + Kopia for automated backup with cloud storage integration
  • Technical Documentation: Created comprehensive documentation site with 50+ guides covering installation, configuration, and troubleshooting

Technical Environment:

  • 5x Raspberry Pi 5 nodes (16GB RAM each) with NVMe SSDs and PoE+ power
  • Synology NAS for persistent storage via iSCSI
  • UniFi networking (UDM Pro, USW-Pro-24-POE)
  • Multi-VLAN architecture (Kubernetes, Home, IoT, Work VLANs)
